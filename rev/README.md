# rev/ について

SEOカルテ（診断レポート）で指摘した項目のうち、静的HTMLの修正で対応できるものを反映した作業用コピーです。
`rev/` 配下のファイルは、そのままWordPress側の該当ページに貼り戻すか、差分を参考にして手動で反映してください。

## 対応済み

### 全ページ共通（19ページすべて）
- `viewport` タグに `initial-scale=1` を追加
- `<meta name="generator" content="WordPress ...">` を削除（CMSバージョンの露出防止）
- GA4のプロパティIDが2つ同時稼働している箇所にTODOコメントを追加（意図を確認の上、不要な方を停止してください。中身は変更していません）

### index.html（トップページ）
- ユーザー提供の文字コード修正版をベースに、以下を追加で反映
  - JSON-LDに `Physician`（院長情報）を追加し、`@graph` 構成に整理
  - 院内・設備・アクセス写真など、内容のある画像に文脈から推定したalt文を追加（★下記「要確認」参照）
  - 本文中に混入していたChatGPTのWeb画面のHTML（`data-message-model-slug="gpt-5-3"` 等）をプレーンテキストに貼り直し（「ご挨拶」文、お知らせ「7/1からオンライン診療開始のお知らせ」の2箇所）

### access.html
- `/access/` と完全に重複していたため、`noindex` + `canonical` + `meta refresh` による暫定リダイレクトスタブに置き換え
- 本来はWordPress側（Redirectionプラグイン等）での301リダイレクト設定が正式な対応です

## 未対応・要確認（次のステップ）

1. **`/news/index.html` の文字化けが未修正**です。トップページと同様に文字コードが壊れており、本レポートのalt文・JSON-LD追加などの精査ができていません。文字コード修正版をいただければ同様に対応します。
2. **他17ページ（/doctor/ /fast/ /price/ 等）の画像alt文・ページ別JSON-LD追加はまだ未着手**です。これらのページは文字化けしていなかったため内容は正しく読めていますが、index.html で行ったような画像alt文の個別追加、症状ページへのFAQPage/MedicalWebPageスキーマ追加はまだ反映していません。優先度の高いページ（/fast/ 頭痛外来、/doctor/ 医師紹介など）から順に対応することを推奨します。
3. **GA4プロパティの重複**は意図確認が必要なため、コード上はTODOコメントを残すのみで、実際の停止は行っていません。
4. **医療広告ガイドライン確認事項**：トップページの「国内最高峰の慈恵医大内視鏡センターで研鑽を積んだ」という表現について、断定的な最上級表現に該当しないか、貴院の医療広告ガイドライン担当者にご確認ください（本レポートでは判断していません）。
5. index.htmlに追加したalt文・JSON-LDの`availableService`一覧は、実際の写真やページ内容と齟齬がないか、公開前に一度目視でのご確認をお願いします（Claudeは画像を直接見て確認したわけではなく、周辺テキストの文脈から推定しています）。
